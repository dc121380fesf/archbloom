# STEP 真曲面：设计记录与进展

> 2026-10-18。**S1 完成**（圆柱侧面写成 `CYLINDRICAL_SURFACE`），
> 但布尔件受阻于面片合并的洞质量。

## 当前状态

| 场景 | 结果 |
|---|---|
| 圆柱体（无布尔） | ✅ 3 面 / 3 边（Circle 2 + Line 1），体积误差 2e-12 |
| 开孔板（经过布尔） | ⚠️ **自动退回全平面**（护栏生效） |

## 已解决：CIRCULAR_ARC 不是标准实体

第一次写用了 `CIRCULAR_ARC`，FreeCAD 不认，退化成 `Line`，体积算成 `6.67e+101`。

**ISO 10303-42 里没有 `CIRCULAR_ARC`**（那是 AP242 的扩展）。正确做法也不是
`TRIMMED_CURVE`，而是——

## 关键：整圆就是一条闭合边

对照 FreeCAD（OCC 内核）导出的圆柱 STEP：

```
#21 = EDGE_CURVE('',#22,#22,#24,.T.);   ← 起点终点是同一个 VERTEX_POINT
#24 = CIRCLE('',#25,5.);
```

**整圆一条边**，不裁剪、不拆半圆。侧面环 4 条 ORIENTED_EDGE：

```
顶圆(.F.) → 母线(.F.) → 底圆(.T.) → 母线(.T.)
```

顶/底面各一条边，引用同一批圆边（否则壳在圆环处断成两半）。

## 已解决：布尔丢失曲面标注

`rebuild.rs` 重建面时无条件写 `Surface::Plane`，导致**任何布尔运算之后，
圆柱面的身份全丢**（实测开孔板 169 个面全是 plane）。

修法：`Polygon` 加 `surface` 字段，贯穿 `split_all` → `select_faces` → `rebuild`。
修完开孔板 64 个孔壁面重新带上 `Cylinder` 标注。

## 新卡点：合并产出碎片洞

诊断合并后的带洞面：

```
面 0: 外环 26 点，洞 1 个，洞的顶点数 [6]
  洞: 半径 0.000487~0.001093  相对差 55%
```

**47 个"小洞"是拼接留下的碎片，不是圆孔。** 于是：

- 孔口边界写不成圆边
- STEP 壳不闭合、体积错（2131 vs 1607）

这是 `merge_coplanar` 的质量问题，不是 STEP 写出器的问题。

## 安全护栏

`to_step_impl` 在走曲面路径前先检查：**所有带洞面的洞必须是圆**，否则整份退回全平面。

宁交已知正确的多面体，不交「看起来有曲面但几何错」的文件。

## 下一步：合并必须产出整洞

要让真曲面在布尔件上落地，得让 `merge_coplanar` 把 64 个孔壁碎片拼成一个完整的
圆洞（而不是 47 个碎片洞）。方向：

1. 拼接时优先沿"洞边界"方向合并，而不是沿外框
2. 或者：合并完成后做一次「洞归并」——把共圆且相邻的洞碎片再拼起来
3. 验收：带洞面数量 = 1（顶/底各一个洞），洞的顶点数 = 圆柱段数，半径相对差 < 1e-6

## 已知坑（都踩过了）

- `AXIS2_PLACEMENT_3D` 的参考方向决定角度零点，写错弧会跑到对面
- 圆心是 `origin + axis*h`，**不是** `p - axis*h`（后者把径向分量留在圆心坐标里）
- 缓存 key 不能带轴方向符号（底面 −Z 与缓存 +Z 永不匹配）
- 缓存 key 必须消灭**负零**（`-0.0000` ≠ `0.0000`）
- `ORIENTED_EDGE('',*,*,#21,.T.)` 里 `*` 与 `#21` 之间**要有逗号**
