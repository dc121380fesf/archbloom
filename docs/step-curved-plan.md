# STEP 真曲面：设计记录

> 2026-10-18 深夜起手。这份文档记录的是「为什么」和「难在哪」，
> 代码骨架写过一版但因为圆弧表示错误被撤回——不接进写出器，
> 因为半真半假的 STEP 比全平面更危险。

## 为什么必须做

现在孔壁在 STEP 里是 128 个平面拼的棱柱。加工厂读进去，看到的是「一堆多边形」，
不是「一个 Φ10 的孔」。写 CNC 代码时它按多边形走刀，不会按圆孔走。

只有 `CYLINDRICAL_SURFACE` + `CIRCULAR_ARC` 才叫真正的孔。

## 硬约束（这是整件事的难点所在）

**曲面上的边必须是曲线。**

不能在一个 `CYLINDRICAL_SURFACE` 面上用折线当边界——那让文件语义自相矛盾：
边的每个点都该落在曲面上，折线的中间段却不在。读入端要么拒绝，要么静默算错。

所以必须**成对**交付：曲面 ↔ 圆弧边。做不到就整组退回平面折线，
**不允许半真半假**。

## 一个完整圆柱侧面在 B-rep 里长什么样

```
┌──────── 顶圆（逆时针，从外面看）
│
│   ┌── seam（母线，同一条边出现两次，方向相反）
│   │
└───┴──── 底圆（顺时针）
```

边界是一个环：
1. 底圆（整圈，拆成两段半圆）
2. 母线（上去）
3. 顶圆（整圈，反向，拆成两段半圆）
4. 母线（下来，与第 2 步是同一条 `EDGE_CURVE`，方向相反）

**seam edge 是 STEP 里合法且常见的结构**——同一条边在环里出现两次，
这是「圆柱面在 B-rep 里必须切开才能参数化」的直接后果。

## CIRCULAR_ARC 不能是 360°

STEP 的 `CIRCULAR_ARC` 由 `AXIS2_PLACEMENT_3D` + 起始角 + 终止角定义。
如果起始角 = 终止角（或差 2π），端点重合，弧退化成点。

**所以整圆必须拆成两段半圆**（或更多）。OCC 的做法是两段。

我第一版骨架把角度写死成 `π/2`，还把参考方向算错了——这正是撤回来的原因。

## 判断「这组侧面片能不能当整筒」

必须全部满足：
1. 同一 `Surface::Cylinder` 参数（origin / axis / radius 在量化容差内一致）
2. 顶点分两层（沿轴坐标只有两个值），且两层点数相同
3. 每个顶点到轴的距离 = radius（离散圆柱的顶点精确在圆上）
4. 每层的角度覆盖接近 360°

任何一条不满足 → 这组不是完整筒（被布尔切掉一块、或者是相贯孔的部分壁）
→ 退回逐面折线。

## 验收口径

- FreeCAD 1.1.2 独立回读：`isValid()` 为 True、体积与我们的三角化一致（±1e-6）
- 读回后**面的类型**确实是 `Cylinder`，不是 `Plane`
- `edges` 里出现 `Circle` 类型的边

## 已知坑

- 我们的圆柱侧面是 64 段离散的，顶点在圆上但**角度可能不均匀**（布尔切分后）
  → 拆半圆时要按「角度中点」取，不能按索引中点
- 顶圆方向和底圆相反（一个顺时针一个逆时针），写反了会让面的法线朝里
- `AXIS2_PLACEMENT_3D` 的参考方向决定角度零点，写错会让弧跑到对面
