# 圆角（fillet）实现笔记

> 2026-10-18。**几何公式已验证正确，角部拼接未完成。**

## 与倒角的区别

| | chamfer（已可用） | fillet（本笔记） |
|---|---|---|
| 连接面 | 一个平面 | 一段圆弧 |
| 图纸 | `C0.5` | `R0.5` |
| 加工 | 铣刀斜切 | 球头刀走弧 |

倒角是「切掉一个角」，圆角是「磨圆一个角」。

## 已验证正确的几何

对凸边，两侧面法线 `n1`、`n2`，内法线 `m1 = -n1`、`m2 = -n2`：

```text
bis = normalize(m1 + m2)              角平分线
θ   = π - acos(n1·n2)                 内部二面角
c   = 边点 + bis * (R / sin(θ/2))     圆心
p1  = c - R*m1                        切点（落在 f1）
p2  = c - R*m2                        切点（落在 f2）
```

90° 凸边 R=0.2 时：`c=(0.2, 0.2)`，切点 `(0.2,0)` 和 `(0,0.2)`——距边都是 R。

**实测验收**（盒子 2m 边长，单边 R=0.2）：

| 段数 | 体积 | 理论 7.982832 |
|---|---|---|
| 1 | 7.984379 | |
| 8 | 7.988286 | |
| 32 | 7.988538 | |

误差 0.07%，方向正确。

## 踩过的坑

**弧的转向差 180°**。圆弧要从「圆心指向切点」的方向插值，也就是 `-m1 → -m2`，
不是 `m1 → m2`。写成后者会把弧甩到实体外面——实测 90° 边转到 z=0.38，
体积差 5 倍（7.385 vs 8.0）。

修法：起点 `-m1`，绕边方向转正角；转向符号用 `dot(cross(from, to), axis)` 判定。

## 未完成：角部

**水密仍为 false**。两个层次的缺口：

### 1. 顶点周围的面没全参与内缩

盒子一个顶点连 3 条边、3 个面。圆角只改了「边两侧的那 2 个面」，
第三个面上该顶点还是原始位置，留缝。

### 2. 边的**分段不够**（试着修了，没成）

给每个顶点补了一个「把所有切点绕顶点排序」的多边形，
面数从 54 → 62，但孤边反而有 **132 条**。看位置：

```
面1: (2.000,1.800,2.000)-(0.200,2.000,2.000)   ← 顶面的一条边横跨整个面
面9: (0.000,-0.000,0.200)-(2.000,-0.000,0.200)  ← 侧面同理
```

**顶面的边没有分段**。盒子顶面只有 4 个顶点，每个顶点周围有 3 条圆角边
（2 水平 + 1 竖直）→ 3 个切点。但边是直的、没有中间点，
两个切点直接连成一条横跨整个面的长边，两侧面的对应切点又对不上。

### 为什么比倒角难

| | chamfer | fillet |
|---|---|---|
| 角部切点 | 3 个（每面一个） | **6 个**（每条边在两侧各一个） |
| 补面 | 一个三角就能封 | 还要与三块圆角面共享边 |
| 边的分段 | 不需要 | **需要**（弧要接到相邻面的切点） |

## 下一步（要重新设计，不是补几行）

1. **边分段**：一条圆角边要按「端点切点 → 中间段 → 端点切点」组织，
   中间段与相邻面的切点对齐
2. **顶点周围的切点组织**：按「面-边」二维关系排，而不是简单绕角度排
3. 角部补面：球面三角（三块圆角面交汇处的真实形状）
4. 然后升级真圆柱面

这一步的核心是**拓扑对齐**，不是几何公式——公式已经验证过了。
