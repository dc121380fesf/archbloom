# 圆角（fillet）实现笔记

> 2026-10-18。**几何公式已验证正确，角部拼接未完成。**

## 与倒角的区别

| | chamfer（已可用） | fillet（本笔记） |
|---|---|---|
| 连接面 | 一个平面 | 一段圆弧 |
| 图纸 | `C0.5` | `R0.5` |
| 加工 | 铣刀斜切 | 球头刀走弧 |

倒角是「切掉一个角」，圆角是「磨圆一个角」。

## 已验证正确的几何

对凸边，两侧面法线 `n1`、`n2`，内法线 `m1 = -n1`、`m2 = -n2`：

```text
bis = normalize(m1 + m2)              角平分线
θ   = π - acos(n1·n2)                 内部二面角
c   = 边点 + bis * (R / sin(θ/2))     圆心
p1  = c - R*m1                        切点（落在 f1）
p2  = c - R*m2                        切点（落在 f2）
```

90° 凸边 R=0.2 时：`c=(0.2, 0.2)`，切点 `(0.2,0)` 和 `(0,0.2)`——距边都是 R。

**实测验收**（盒子 2m 边长，单边 R=0.2）：

| 段数 | 体积 | 理论 7.982832 |
|---|---|---|
| 1 | 7.984379 | |
| 8 | 7.988286 | |
| 32 | 7.988538 | |

误差 0.07%，方向正确。

## 踩过的坑

**弧的转向差 180°**。圆弧要从「圆心指向切点」的方向插值，也就是 `-m1 → -m2`，
不是 `m1 → m2`。写成后者会把弧甩到实体外面——实测 90° 边转到 z=0.38，
体积差 5 倍（7.385 vs 8.0）。

修法：起点 `-m1`，绕边方向转正角；转向符号用 `dot(cross(from, to), axis)` 判定。

## 未完成：角部

**水密仍为 false**。原因：圆角把边的两个端点内缩成切点，但**其他也包含这个顶点的面没跟着改**，
留了缝。

一个顶点周围有多个面（盒子的角是 3 个），圆角只改了边两侧的那 2 个。
要闭合，得让**顶点周围所有面**协调——这是圆角最难的模块，OCC 的 fillet 也是最复杂的部分。
