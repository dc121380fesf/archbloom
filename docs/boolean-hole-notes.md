# 连续布尔为什么崩

> 记录日期：2026-10-19
> 状态：**未修**，根因已定位，需要架构级改动

## 现象

拿一个真实零件测（安装板 100×80×10，4 个 Φ8 通孔 + 30×20×5 方槽）：

| 布尔次数 | 水密 | 欧拉 | 体积误差 |
|---|---|---|---|
| 光板（0 次）| true | 2 | **0**（解析值）|
| 1 个孔 | true | 0 | 0.046% |
| 2 个孔 | **false** | -18 | 0.095% |
| 3 个孔 | false | -62 | 0.100% |
| 4 个孔 | false | -118 | **5.03%** |
| 1 孔 + 方槽 | true | 0 | **34%** |

**只有第一次布尔可靠。**

## 根因：`Polygon` 没有洞

布尔链的中间态是 `Polygon`：

```rust
pub struct Polygon {
    verts: Vec<Point3>,
    plane: Plane,
    surface: Option<Surface>,
    // 没有 holes
}
```

布尔三步（`csg::split_all` → `select_faces` → `rebuild::polygons_to_solid`）
全程假定「一个多边形 = 一个简单环」。

而**第一次布尔的输出恰好产生带洞面**：开孔板的顶面是「外环 132 点 + 孔环 64 点」。
把它喂给第二次布尔时：

- `solid_to_polygons` **只读 `f.verts`，`f.holes` 一字没读**
- 于是顶面变成「一块实心板」，孔消失
- 第二次布尔挖槽时，它算的是一个没有孔的体积

实测「1 孔 + 方槽」体积 0.0001028 而理论 0.0000765——**比光板还大**，
因为孔被填上了。

## 试过的两个修法，都不成

### 修法一：带洞面三角化

让 `solid_to_polygons` 对带洞面调 `triangulate_face`，每个三角形一个 `Polygon`。

**结果更糟**：三角化出来的边只属于三角形自己，**不与其他面共享**。
重建时焊不上——7217 顶点 / 7257 面，面比顶点还多，欧拉 -14，直接 panic：

```
TopologyBroken { reason: "重建后不水密（7217 顶点 / 7257 面；欧拉数 -14）" }
```

（代码已回退。）

### 修法二：中间合并后再布尔

每次布尔后先 `merge_coplanar` 把碎片合成整面（70 面，水密、欧拉 0），
再喂下一次。

**同样崩**：合并后的面恰恰是带洞面，第二次布尔还是要面对「洞」。

## 正确修法（未做）

**`Polygon` 必须带 `holes`，且切分/分类/重建三步都要处理洞。**

具体要改的：

1. `Polygon { verts, holes: Vec<Vec<Point3>>, plane, surface }`
2. `split_polygon`：平面切带洞多边形 → 洞也跟着切
3. `select_faces`：点在体内的判断要认洞（洞里的点不算在面内）
4. `polygons_to_solid`：缝合时洞的边界参与建边
5. 重建后的 `Face.holes` 从 Polygon 的 holes 转过来

**工作量**：布尔是这个内核最复杂的部分（`csg.rs` 228 + `boolean.rs` 183 +
`rebuild.rs` 181 = 592 行有效代码），带洞改造会动全部三个文件。

## 现在的能力边界（如实）

**能交付**：

- 光板、盒子（体积精确）
- **只打一个孔**的板（水密、欧拉 0、0.046%）
- 光轴（64 段 0.16%）
- 倒角盒子（1.4e-8）
- 圆角盒子（0.049%）

**不能交付**：

- **任何需要两次以上布尔的零件**——安装板、支座、法兰、带槽的块，
  几乎所有真实零件
- 圆柱圆角（另一个独立问题）

## 优先级判断

**连续布尔比圆角严重得多。**

圆角是「有功能缺一块」；连续布尔是「基础能力不可靠」。
之前一直用「单孔开孔板」当验收样本，所以看起来精度很好——
样本选得太窄了。
